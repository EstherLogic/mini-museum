# 🖼️ Mini Museum Website

A colorful and interactive multi-page museum website built with HTML and CSS.

The project presents a small digital museum where visitors can explore artists, discover artworks, view the museum location, and learn about ticket prices.

---

## ✨ Features

- 🏛️ Museum homepage with welcome section
- 🎨 Artists page with artist biographies
- 🖼️ Interactive artwork gallery
- 🔍 CSS-based artwork popup / lightbox
- 📍 Museum location with Google Maps
- 📞 Contact information
- 🎟️ Ticket pricing table
- 📱 Responsive design for different screen sizes
- ♿ Semantic HTML and accessible image descriptions
- 🎬 Museum tour video support
- 🎵 Audio support for artist content

---

## 👩‍🎨 Featured Artists

The museum currently features:

- **Vincent van Gogh**
- **Claude Monet**
- **Pablo Picasso**

Each artist has a dedicated section with:

- Portrait
- Short biography
- Artwork gallery
- Navigation directly to their collection

📄 Pages
🏠 Home

The main landing page introducing the museum and providing navigation to the different sections.

👩‍🎨 Artists

Information about the featured artists, including portraits, biographies, and links to their artwork collections.

🖼️ Gallery

A collection of artworks organized by artist.

Clicking an artwork opens a larger view using a CSS-based popup effect.

🚀 How to Run

No installation is required.

Simply open:

index.html

in a web browser.

💻 Local Setup

Clone the repository:

git clone https://github.com/EstherLogic/mini-museum-website.git

Open the project folder:

cd mini-museum-website

Then open index.html in your browser.
